# Гримуар

Тёмный офлайн-блокнот (PWA) в одной семье с «Ноктюрном» и «Реквиемом»: строгий монохром, плёночное зерно, готика, терновые орнаменты.

## Что умеет
- Записи двух видов: **текст** и **список** с чекбоксами. Вид можно сменить в любой момент, ничего не потеряется.
- Автосохранение. Пустая запись при выходе не сохраняется.
- **Закрепление** (крест на карточке) и **светлая страница**: инверсия вместо цветного акцента.
- **Метки**: фильтр-чипы над записями, экран «Метки» с переименованием и удалением.
- Поиск по заголовкам, тексту, пунктам и меткам.
- Долгое нажатие на карточку открывает быстрые действия.
- **Архив** и **корзина**. Записи в корзине хранятся 30 дней. У действий есть кнопка «отменить».
- Копия всех записей в JSON и восстановление из копии (слияние: новые записи добавляются, более свежие версии заменяют старые).
- Работает офлайн, ставится на главный экран. Системная кнопка «назад» закрывает окна, а не выходит из приложения.

## Запуск
```bash
npm install
npm run dev
```
Откроется по адресу http://localhost:5173.

```bash
npm test          # тесты логики
npm run build     # сборка в dist/
npm run icons     # перегенерировать иконки
```

## Публикация на GitHub Pages
Так же, как у календаря и плеера: репозиторий на GitHub, ветка `gh-pages`.
```bash
npm run deploy
```
Команда прогоняет тесты, собирает проект и выкладывает `dist` в ветку `gh-pages`.

## Устройство
```
src/
  domain/      чистая логика: записи, списки, метки, даты, бэкап (+ тесты)
  db/          Dexie (IndexedDB): таблица notes
  components/  карточки, редактор, шторки, SVG-графика
  screens/     Записи, Метки, Ещё (архив, корзина, копия)
sw/sw.js       service worker; список файлов подставляется при сборке
```
Записи хранятся только на устройстве. Время от времени сохраняй копию в «Ещё».
